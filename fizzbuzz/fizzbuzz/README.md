# FizzBuzz

Projeto desenvolvido em Python para praticar estruturas condicionais, funções e loops.

## Funcionamento

O programa recebe um número e executa o FizzBuzz para cada número de `1` até o valor informado.

As regras utilizadas são:

- Divisível por 3 e por 7 → `FizzBuzz`
- Divisível apenas por 3 → `Fizz`
- Divisível apenas por 7 → `Buzz`
- Contém o dígito `3` → `Almost Fizz`
- Nenhuma das condições anteriores → o próprio número
