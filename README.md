# Projetos e Desenvolvimento em Python

Repositório criado para registrar minha evolução durante meus estudos de programação com Python.

## Projetos

### Daily Expense Tracker

Gerenciador de despesas desenvolvido em Python. O programa permite adicionar e listar despesas, calcular o total e a média dos valores registrados e limpar os dados por meio de um menu interativo no terminal.

**Conceitos utilizados:** `while`, `if/elif/else`, listas, `for`, `sum()`, `len()` e `break`.

### FizzBuzz

Projeto desenvolvido para praticar estruturas condicionais, funções e loops.

### Planilha de Vendas

Projeto desenvolvido para praticar matrizes, loops aninhados, acumuladores, `sum()` e f-strings.
