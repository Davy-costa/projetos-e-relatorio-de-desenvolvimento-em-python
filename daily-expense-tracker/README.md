# Daily Expense Tracker

Um gerenciador de despesas diárias desenvolvido em Python para praticar conceitos fundamentais de programação.

## Funcionalidades

O programa possui um menu interativo no terminal que permite:

- Adicionar uma nova despesa
- Listar todas as despesas registradas
- Calcular o total das despesas
- Calcular a média das despesas
- Limpar todas as despesas
- Encerrar o programa
- Tratar opções inválidas

## Conceitos praticados

- `while True`
- `if`, `elif` e `else`
- `break`
- Listas
- `append()`
- `clear()`
- `len()`
- `sum()`
- `for`
- `range()`
- `input()` e `print()`
- Conversão de dados com `float()`
- F-strings
