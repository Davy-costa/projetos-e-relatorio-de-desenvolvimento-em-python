# Planilha de Vendas

Projeto desenvolvido em Python para simular uma planilha de vendas utilizando uma matriz (lista de listas).

## Funcionamento

O programa organiza os dados de vendas de diferentes vendedores ao longo de três meses e exibe cada venda relacionando:

- Vendedor
- Mês
- Valor da venda

## Conceitos praticados

- Matrizes (listas de listas)
- `for`
- Loops aninhados
- `range()`
- `len()`
- Índices de listas
- F-strings
- `print()`

## Como executar

Tenha o Python instalado e execute o arquivo pelo terminal:

```bash
python 20_planilha_vendas.py
